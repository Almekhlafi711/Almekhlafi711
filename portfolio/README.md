# Full Stack Developer Portfolio (PHP + MySQL)

## Run locally on XAMPP
1. Copy the `portfolio` folder into `htdocs`.
2. Start Apache and MySQL from XAMPP.
3. Open phpMyAdmin and import `portfolio/database.sql`.
4. Browse to `http://localhost/portfolio/`.

## Admin Login
- URL: `http://localhost/portfolio/admin/login.php`
- Username: `admin`
- Password: `admin123`
